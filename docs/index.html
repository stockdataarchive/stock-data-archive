Read a free AAPL sample

The website's free samples include one day of AAPL minute bars, trades and quotes, plus daily bars. You can inspect them without an account.

After the one-time setup, run the sample-file example:

python examples/aapl_sample.py

It downloads the minute-bar Parquet file, checks its fingerprint, converts timestamps to New York time and writes CSV. For November 9, 2026, it finds 846 bars: 276 pre-market, 390 in the regular session and 180 after hours.

The file documentation explains the timestamp and price columns. DuckDB queries are included for inspecting the same file with SQL.

Check listed and delisted coverage

Use the website catalogue to find the dates available for a symbol. The public MCP server exposes the same coverage information to agents and scripts.

python examples/catalogue.py LEH
python examples/catalogue.py AAPL --json

The catalogue example requests coverage, file schemas and sample URLs. For LEH it returns Lehman Brothers' history from September 10, 2003 to September 17, 2008, matching the website's LEH page.

The client uses only public read-only tools and sends no account credentials. Its JSON option prints the full results for another program. See the MCP setup guide to connect Claude Code, Codex, Cursor or another client.

Backtest an opening range breakout

The opening range is the high of AAPL's first 30 regular-session minutes. The first later minute to cross that high starts at 10:24 AM Eastern. For this example, the strategy waits until that minute finishes, enters at 10:25 and exits at 3:55 PM.

The minute-bar reference uses the open of each execution minute. The quote model buys at the last observed ask and sells at the last observed bid. The midpoint row below uses those same quote snapshots; it shows how much of the difference comes from crossing the spread.

The bar-to-quote gap is 10.5 cents per share. Crossing the spread accounts for 7 cents at these snapshots. The other 3.5 cents comes from the difference between minute opens and quoted midpoints. Calling the whole gap the spread would overstate it.

Five-minute sampled closes, New York time. The backtest uses every regular-session minute; the chart is a summary.

This is an execution example for one historical trade. It does not estimate the strategy's win rate or performance across other days. Displayed quotes are hypothetical fill prices, not proof that an order would have filled.

Entry at 10:25

  1. Build the range. Use the 30 bars starting at 09:30 through 09:59 Eastern. Their maximum high is $350.34. That range is complete at 10:00.
  2. Wait for a completed breakout minute. The first subsequent bar with a high strictly above $350.34 starts at 10:24 and reaches $350.43. Its completed high is treated as available at 10:25.
  3. Compare prices at the decision time. The bar reference enters at the 10:25 open. The quote model uses the latest ask strictly before 10:25. Both exit on the clock at 15:55.

A bar timestamp marks the start of the minute. Filling inside the 10:24 minute using its completed high would let the strategy act before that high was known. The example therefore puts the decision at the next boundary. It assumes the finalized bar is available then; actual bar-delivery delay and revisions are not reconstructed.

Quotes are ordered by ts_sip, then sequence number. A quote at the exact requested execution timestamp is excluded because the ordering between streams is ambiguous. The selected quote must have positive prices and sizes, an ask at least as high as the bid, and an age of one second or less.

The zero-delay entry quote is 80.286 milliseconds old. The exit quote is 0.757 milliseconds old. The latency options below move both execution times forward; the minute-open reference stays fixed.

Reproduce the study

Use Python 3.10 or later. The script downloads the three public sample files, checks their pinned SHA-256 hashes and writes the results. No account or API key is required.

git clone https://github.com/stockdataarchive/stock-data-archive.git
cd stock-data-archive
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/backtest.py
python -m unittest discover -s tests

Existing downloads can be passed with --data-dir /path/to/samples. Files stay in the ignored cache; this repository publishes code and calculated summaries. Market data use follows the dataset license.

Read the bar timestamps in DuckDB

SELECT
  to_timestamp("timestamp" / 1e9)
    AT TIME ZONE 'America/New_York' AS bar_start,
  open, high, low, close
FROM read_parquet(
  'https://stockdataarchive.com/samples/AAPL_2026-11-09_1min.parquet'
)
ORDER BY "timestamp"
LIMIT 5;

The conversion above is for display. The backtest compares timestamps as integer nanoseconds, preserving their precision for quote matching.

Input checks

The files contain 846 minute bars, 754,422 trades and 517,808 quotes. All 390 regular-session minutes are present and contiguous. The script checks for unexpected symbols, duplicate or misaligned bar timestamps, missing opening minutes and inconsistent OHLC values.

Across the full quote file, 435 rows have nonpositive prices or sizes, or a crossed market. Neither baseline execution snapshot fails those checks. The code selects the latest quote first, then validates it. Filtering bad rows before selection could incorrectly bring an older quote back into use after the latest quote had withdrawn.

Assumptions to keep in view

Historical bars may differ from what arrived live.

The example uses finalized OHLC bars and assumes each is available at the next minute boundary, before any selected added delay. Late reports, bar revisions and trade-condition eligibility are not reconstructed.

Minute OHLC does not contain the bid-ask spread.

Quotes provide an observed spread. A spread estimated from volatility, volume or a fixed basis-point charge remains a model assumption. Without quotes, test a range of costs and report the break-even cost.

The next minute's high is an adverse scenario, not an observed fill.

That high is known only after the next minute finishes. Using it as a long-entry stress test can be useful, but it mixes timing uncertainty with spread and price movement. Use comparable assumptions on the exit.

One trade cannot establish a strategy's performance.

A broader test needs more periods, a predefined universe, out-of-sample evaluation and explicit treatment of delistings and corporate actions. This sample does not support an annualized return, Sharpe ratio or win-rate estimate.
